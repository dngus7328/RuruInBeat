# 마우스 모드 UI 가독성 자체 검토 기록 (2026-11-23)

## 검증 범위와 도구
Unity Editor 실행이 불가능한 환경에서 저장소의 실제 `CanvasScaler`, `RectTransform` 앵커, UI 코드와 제작 PNG 20개를 읽고, Pillow로 해상도별 배치 근사 화면을 렌더링해 검토했다. 본 문서는 **Unity Play Mode 통과 인증이 아니다**. 스크립트 연결과 동작은 Unity 실행 전 미검증 항목으로 남는다.

- Unity `CanvasScaler`: 1920×1080, Scale With Screen Size, match 0.5
- 해상도: 1920×1080 / 1600×900 / 1366×768
- 필수 PNG 20개: 32비트 RGBA, 손상되지 않은 ZIP, 지정 해상도, UI 투명도 점검
- 본문 글꼴 근사: NanumSquare. Unity TMP 폰트가 동일하다고 가정하지 않는다.

## 실제로 발견해 수정한 문제
1. `TutorialGuide/ChapterIndex` 텍스트가 프레임 상단에 너무 가까웠다. 앵커를 낮추고 글자 크기를 18→24(기준 해상도)로 늘렸다.
2. 튜토리얼 아이콘이 작은 화면에서 너무 작게 보였다. `ControlIcon` 슬롯을 확대했고, 본문 영역을 겹치지 않도록 조정했다.
3. 안내 본문 20→22(기준 해상도). 모든 6개 안내 문장은 3개 목표 해상도에서 테스트 글꼴 기준 1~2줄로 들어가며, 할당된 본문 높이를 넘지 않았다.
4. 튜토리얼 대화창 버튼이 1366×768에서 약 38px 높이로 작았다. 앵커를 바꿔 동일 해상도에서 약 49px가 되게 하고, 대사 본문의 최저 위치를 올려 버튼과 세로 영역 충돌을 제거했다.
5. 별도 전달 PNG의 `UI_Panel` 모서리 장식이 9-slice 경계에 걸쳐 늘어나거나 상단 텍스트와 맞닿았다. 모서리 단일 포인트로 정리했다. GitHub 코드 생성기는 기존 PNG가 있을 때 덮어쓰지 않는다.

## 해상도별 확인 수치 (근사 화면)
| 대상 | 1920×1080 | 1600×900 | 1366×768 |
|---|---:|---:|---:|
| 튜토리얼 대화 버튼 높이 | 70px | 58px | 49px |
| 튜토리얼 대사 본문 영역 높이 | 130px | 108px | 92px |
| 튜토리얼 가이드 본문 영역 높이 | 94px | 79px | 67px |
| 튜토리얼 안내 본문 글자 크기 | 22px | 18px | 16px |
| 안정화 게이지 가로폭 | 520px | 433px | 370px |

- `UI_Panel` 중앙 배경과 자주보라 문자 대비: 14.72:1(가이드 컬러, WCAG 계산)
- 가이드 본문 텍스트와 크림 배경: 9.89:1
- 단계 번호 텍스트와 라벤더 스트립: 5.11:1
- 안정화 게이지 프레임 중앙은 실제로 투명하며, 트랙/채움은 별도 RGBA 이미지
- `raycastTarget=false`가 튜토리얼 아이콘과 안정화 HUD에 적용됨을 코드로 확인

## 아직 검증했다고 주장할 수 없는 항목
- 실제 Unity Game View 스크린샷/폰트/TMP 레이아웃/애니메이션
- 곡 선택 6곡 및 탄막의 실시간 시인성(게임 플레이/원본 음원 및 프레임 조건 필요)
- 자동 에셋 생성 시 Sprite Import, 컴파일, Scene 오브젝트 동작 검증
- 스토리/타이틀/설정 등 나머지 조건부 작업의 완성도

사용자에게 테스트를 맡겼다는 의미가 아니라, 이 실행 환경에 Unity Editor 자체가 없어서 현재 수행할 수 없는 검증을 명시한 것. 실제 플레이 검증 전에는 전체 검증 완료로 표기하지 않는다.
