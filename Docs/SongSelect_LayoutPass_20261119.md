# 곡 선택 화면 레이아웃 재정비 (2026-11-19)

이 문서는 실제 **Unity Scene YAML**과 **런타임 Browse UI**의 레이아웃을 함께 수정한 기록입니다. 기능 추가보다 정보 위계, 일정한 간격, 필터 조작성을 우선했습니다.

## 구성 원칙
- 16:9 PC Game View를 중심으로 배치하고, Panel별 RectTransform Anchor로 화면 크기 변화에 대응
- 좌측 약 58%는 **검색 / 작은 필터·정렬 / 카트리지 2열×3행 / 필요할 때만 페이지 표시**
- 우측 약 42%는 **실제 곡 자켓 / 선택 곡명 / BPM·재생 시간 / 자동 미리듣기 ON·OFF와 진행바**
- 자켓과 카트리지 크기는 줄이지 않고, 다른 버튼은 보조 조작임을 드러내도록 작게 유지
- 어두운 보라·라벤더 매트톤, 과한 글로우/광택/네온 없이 구분. 중복 설명문·숫자·임시 장식은 추가하지 않음

## 배치 개선
- `Assets/Scene/SongSelectScene.unity`: 화면 위 제목과 뒤로가기 버튼의 수평선/정렬을 통일
- 왼쪽 6개 카트리지의 Anchor 폭·높이와 가로/세로 간격을 통일하고 3행을 더 균등하게 배치
- 오른쪽 자켓 프레임과 이미지 비율을 유지하면서 제목과의 사이를 확보하고, 제목/정보/미리듣기 막대의 **왼쪽 기준선**을 맞춤
- 왼쪽 하단 페이지 컨트롤은 7곡 이상일 때만 표시하고, 우측 하단에 작게 배치
- 검색창은 넓게, 필터·정렬 버튼은 작은 동일 높이로 정리. 작은 정렬 버튼에 맞는 '곡명순/레벨순/BPM순' 다국어 문구 추가

## 필터 패널
- 작은 `필터` 버튼으로 진입합니다.
- 과거에는 왼쪽 곡 목록 위에 나타나 카트리지를 가렸습니다. 지금은 **오른쪽 곡 정보 영역을 대신하는 패널**로 열리므로 목록이 가려지지 않습니다.
- 레벨/BPM 두 범위 선택 막대는 각자의 제목, 값, 조작 부분을 세로로 구분해 배치했습니다.
- 활성화 시 0.18초의 짧고 절제된 가로 슬라이드+페이드; 닫기/초기화 유지.
- `Esc`는 열린 필터를 먼저 닫습니다. 필터가 없을 때만 타이틀로 돌아갑니다.
- 검색·정렬·페이지 이동과 첫 클릭 선택/재클릭 게임 시작 동작 유지.

## 실제 확인 시 점검할 항목
1. Unity Play Mode에서 검색/필터/정렬 버튼이 같은 높이로 보이는지
2. 여섯 카트리지의 상하좌우 여백과 긴 한국어 곡명의 잘림 여부
3. 오른쪽 필터 패널이 목록을 **가리지 않는지**, 슬라이드 중 깜박임은 없는지
4. 마우스 드래그로 레벨과 BPM 범위가 실제로 바뀌는지
5. 필터 패널에서 Esc를 누르면 곡 선택 화면에 남고, 두 번째 Esc에서 타이틀로 돌아가는지
6. 실제 `songSelectJacket`가 할당된 곡에서 비율을 유지하는지
7. 7곡 이상일 때 페이지 조작, 모든 곡의 선택·재클릭으로 게임 진입, 미리듣기 ON/OFF

**검증 범위:** 연결된 C# 메서드, Localization 키, YAML의 fileID와 카트리지 RectTransform 겹침 여부를 정적으로 검사했습니다. Unity Editor/컴파일/Play Mode에서의 화면 검증은 수행하지 못했습니다.
