# 곡 선택 UI: 검색 · 필터 · 페이지 이동 (2026-11-19)

## 적용 씬
`Assets/Scene/SongSelectScene.unity` 한 개만 사용합니다. 이전의 중복 곡 선택 씬은 복구하지 않았습니다.

## 사용 방법
- **곡명 검색**: 왼쪽 상단 검색창에 문자 일부 입력. 한국어/영어/일본어 곡명 부분 일치 검색 (대소문자 구분 없음). 입력 변경 시 즉시 목록을 갱신합니다.
- **레벨 필터**: 전체 / 1~5 / 6~10 / 11~15. 한 곡당 하나의 대표 채보만 기준으로 하며, 검색과 필터를 동시에 사용합니다.
- **정렬**: 정렬 버튼을 클릭해 곡명 → 레벨 → BPM → 곡명 순환. F2 단축키도 유지합니다.
- **페이지**: 한 페이지 6곡(2열×3행). 아래 〈/〉 버튼이나 목록 위 마우스 휠로 6곡 단위 페이지 이동. 페이지 번호와 검색에 일치하는 곡 수가 표시됩니다.
- **선택**: 카트리지를 한 번 클릭하면 선택·정보 갱신·미세 전진 애니메이션이 재생됩니다.
- **시작**: 같은 카트리지를 다시 클릭하면 카트리지 복제가 오른쪽 커버 쪽으로 날아가며 축소된 다음, 선택한 채보로 `Mouse` 씬에 진입합니다. 별도의 게임 시작 버튼은 없습니다.

## 화면 구성
- 위쪽: 곡 선택 제목 및 타이틀 돌아가기 버튼, 검색/정렬/필터
- 왼쪽: 2열 3행 카트리지와 얇은 보관 홈, 모든 카트리지의 **중앙 하단**에 동일한 레벨 표시
- 왼쪽 아래: 페이지 이동 〈 01 / 02 〉
- 오른쪽: 기존 `songSelectJacket` 에셋을 표시하는 **정사각형에 가까운 커버 영역**, 곡명·레벨·BPM·재생 시간, 미리듣기와 음량 진행바
- 아래쪽: 중복되지 않는 선택 상태 안내

## 로컬라이제이션
`SongSelectLocalization.cs`의 한국어·영어·일본어 문구표에 새 검색/정렬/레벨 필터/빈 결과 텍스트를 추가했습니다. `SongSelectMenuUI.SetLanguage(...)`에서 검색 UI까지 갱신합니다.

## 실제 게임에서 확인해야 할 경우
1. 6곡 이하에서는 첫 페이지 하나와 비활성화된 페이지 화살표
2. 7곡부터는 두 번째 페이지가 생성되고, 선택/재클릭 동작이 정상인지 확인
3. 검색에 일치하는 곡이 없으면 "검색 결과가 없어요"가 나오며 기존 곡은 눌리지 않음
4. 검색어와 레벨 필터의 교집합만 표시됨
5. 정렬 변경 시 현재 선택 곡을 보존하고, 페이지가 달라져도 정상적으로 재배치됨
6. 실제 재킷 스프라이트가 배정된 경우 커버 이미지가 비율을 유지하는지 확인

`SongSelectBrowseUI.cs`는 씬 Canvas에 연결돼 있으며 **검색창, 버튼, 진행바 UI를 Play Mode에 생성**합니다. 따라서 Unity 편집기 Scene View에서는 기존 레이아웃을 볼 수 있지만, 검색창/필터/페이지 버튼의 실제 모습과 동작은 **Play Mode**에서 확인합니다.

GitHub 스크립트 및 씬 fileID 참조 검사는 수행했지만, 이 작업 환경에서는 Unity Editor Play Mode 실행을 직접 테스트하지 못했습니다.
