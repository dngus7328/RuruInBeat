# 루루 인 비트 — 최신 게임 기획서
2026-11-27. 이전 설계와 충돌할 경우 이 문서 우선. 기획 목표이며 구현 완료 선언이 아니다.

## 개요
PC Unity 1920×1080, 일본 서브컬처풍 인디 리듬 액션 × 탄막 회피. 게임기 내부 세계를 배경으로 루루와 복구 요정 피노의 이야기를 전개한다. 세부 스토리는 기존 데이터 유지.

## 플레이
마우스 이동으로 피노 조작, 좌/우클릭과 휠로 리듬 입력, ESC 일시정지. 기본 잠금 모드에서 입력 종류와 타이밍 판정. 안정화는 판정 및 피격에 따라 변하며 0이면 실패. 100만 점 체계, 콤보와 PERFECT/GREAT/GOOD/MISS 기록. 채보와 탄막은 실제 음원의 악센트와 구절에 맞춘다. 기존 판정 수치와 노트 시스템은 임의 변경하지 않는다.

## 흐름
실행 → 인트로 → 타이틀(클릭/키보드/터치로 진입, CLICK TO START 표시) → 메인 메뉴(플레이/설정/종료, 하단 크레딧) → 최초 스토리·튜토리얼 또는 곡 선택 → 로딩 → READY/3·2·1/GO → 플레이 → 결과 → 재도전/곡 선택.
튜토리얼은 시작 선택 이후 진행하며 다시하기 지원. 이동→좌클릭→우클릭→휠→회피→종합.
곡 선택: 검색, 정렬, 분류, 재킷, 상세 정보, 최고 기록, 미리듣기, 플레이. 곡당 단일 채보.
HUD: 재킷, 곡명, 10구간 안정화, 콤보, 점수만. 진행바/시간/퍼센트/상시 일시정지 버튼 없음.
일시정지: 계속/재시작/곡 선택, 재개 카운트다운.
결과: 클리어/실패, 곡명, 점수, 랭크, 판정 통계, 콤보, 최고 기록, 피노 반응.
설정: 사운드/게임/화면/조작/기타. 종료 확인 지원.

## 데모
튜토리얼 별도, 일반 6곡: BOOTBEAT, Cotton Pulse, Pop'n Dash, Oddbeat Shuffle, 瞬奏 -SHUNSOU-, Full-Band Hit.
