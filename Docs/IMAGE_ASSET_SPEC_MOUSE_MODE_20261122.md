## 1. 가장 먼저 지켜야 할 기준

**캐릭터 원본:** 2026-11-22 사용자 업로드 첫 그림=루루, 둘째 그림=피노. 루루의 매우 긴 짙은 보라 머리/나른한 보라 눈/검은 상의/커다란 연보라 겉옷/고양이 모양 슬리퍼와 피노의 은연보라 짧은 머리/귀/보라 날개 2개/흰·보라 옷/검은 카라·가방 구조를 그대로 유지. **새 디자인으로 그리지 말고 원본을 분리해 쓴다.**

**컨셉:** 흔한 보라색 박스 UI가 아니라 **팝한 2D 애니메이션 PC 리듬게임**. 선명한 큰 색 면, 짧은 사선 포인트, 조금 비대칭인 리듬감, 강한 숫자/콤보 타이포그래피. 게임기를 좋아하는 루루의 취향을 **버튼을 누르는 감각/선택 반응**으로 표현. 프레임 네 모서리마다 게임패드/별/날개를 덕지덕지 붙이지 않는다.

**금지:** 모바일 가챠 카드 UI, 키즈 장난감/젤리 버튼, 메탈 게임기 패널, 유리 재질, 네온/강한 외곽 글로우, 의미 없는 이중·삼중 프레임, 번진 그림자, 글씨가 합성된 PNG, AI풍 가짜 한글, 캐릭터 재디자인.

**폐기된 자산:** Assets/Image/안정화게이지.png와 안정화게이지2.png는 **세로형 4레인 UI이므로 사용할 수 없음**. 구형 Q/W/O/P 키캡/세로판/판정선 PNG도 마우스 모드에 사용 금지.

**절대 수정 금지:** 기존 마우스 노트는 MouseModeChartPlayer.MakeSprites()에서 **코드 생성**. 원형 노트·접근 링·좌/우/휠 구분·휠 경로를 새 PNG로 바꾸지 않는다. 신규 노트 PNG **0장**.

### 1-2. 파일의 물리적 품질

- PNG 32bit RGBA, 배경이 실제 투명. 흰색/검정/체커판/분홍·파랑 잔상 금지. **하나의 이미지 = 하나의 실제 사용할 부품**.
- 프레임/버튼/탭/트랙은 **9-slice 가능한 단순한 중앙 면**, 장식은 고정 모서리 부분만. 이미지의 글씨/숫자/캐릭터는 모두 **별도 레이어**. 클릭 상태는 Unity 색/크기 변화.
- 이미지 원본 px는 **제작 치수**, Unity 표시 px가 아니다. Sliced/Single/Filled 지정은 각 항목 참조.
- 1920×1080 / 1600×900 / 1366×768에서 읽힘과 클릭 범위 검증. 노트·탄막·피노가 최우선이며 그 위를 UI로 덮지 않는다.

- **버튼/탭:** 왼쪽 카테고리는 UI_Tab 하나, 확인/취소/초기화는 UI_Button 공용. 기존 초기화 버튼이 정상이고 그림체가 맞으면 **중복 그림 만들지 않음**.
- **슬라이더:** 3개 Image(Track/Fill/Handle). **토글:** 2개 Image(Track/Handle). ON/OFF 글씨·상태·이동은 Unity. 스크롤이 필요하면 Track 1+Handle 1.
- **개발 병행:** TitleScene의 Lane1KeyRow~Lane4KeyRow 및 PinoLeft/RightKeyRow는 **폐기된 키보드 4레인 설정**이다. 그림만 새로 그려도 해결되지 않으므로 마우스 조작 설정으로 구조 개편해야 한다.
- **화면:** 기존 설정 내용 페이지 1460×730, 범주 탭 5개. 430×170 구형 버튼을 **줄이면서** 오른쪽 제목·슬라이더·토글 텍스트가 잘리지 않게 배치. 한 탭마다 다른 불필요한 프레임 생성 금지.

### 나머지 화면은 신규 이미지 중복 생산 금지
- **PausePanel:** UI_Panel + UI_Button + TMP, ESC로 호출. 화면 우측에 Pause 상시 버튼 붙이지 않기.
- **로딩/전환:** 기존 로고 + Unity 애니메이션으로 처리. 전용 네온 스피너 PNG 불필요.
- **종료/초기화 확인:** UI_Panel + UI_Button 재사용.
- **CreditsPanel:** 동일 패널 + TMP. 사람 이름을 이미지에 굽지 않는다.
- **바이러스·피노·탄막:** 기존 스프라이트와 런타임 로직을 먼저 쓰고, 임의 적 이미지 추가 금지.

### 제작 산출물 합격표

- [ ] **한 파일에 기능 부품 여러 개가 들어간 시트가 아니라** 각 항목 독립 PNG.
- [ ] 모든 투명 PNG가 실제 알파 투명, 배경 잔상/테두리 오염 없음.

- [ ] 글씨/숫자/버튼 상태/게이지 퍼센트/판정이 PNG에 구워져 있지 않음.
- [ ] 패널/버튼/슬라이더의 9-slice 모서리가 여러 크기에서 안 깨짐.
- [ ] 안정화는 Frame/Track/Fill이 각각 별도 Image이고 0~100%가 동작.
- [ ] 튜토리얼 아이콘이 실제 1~4단계에서 각각 바뀌고 노트·탄막을 가리지 않음.

- [ ] 곡별 BG는 플레이 시 접근 링/탄막 경고·피노가 항상 더 눈에 띔.

- [ ] 폐기된 4레인 노트/안정화 게이지 이미지를 마우스 모드에 넣지 않음.
