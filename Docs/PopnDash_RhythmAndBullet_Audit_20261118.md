# Pop'n Dash — 채보 박자 및 탄막 실행 수정 검수 (2026-11-18)

## 대상

- 활성 Unity 채보: `Assets/MouseMode/ChartSystem/Charts/NewMouseChart 2.asset` (Mouse 씬에서 직접 참조)
- 채보 JSON: `Assets/Editor/PopnDash_119_REBUILT.json`
- 음원: `Assets/Song/Pop'n Dash.mp3` (120.432초, 48kHz, 스테레오)
- 탄막: `Assets/MouseMode/MouseModeBulletDirector.cs`와 `Assets/Scripts/MousePlay/MouseModeBulletPatternLibrary.cs`

## 문제 확인

1. **음악 기준 박자와 채보 BPM이 다름.** 음원을 다운샘플링해 onset-strength 반복 주기를 스캔하면 약 **119.26 BPM**으로 나타남. 기존 BPM=119는 그리드와 실제 반복 리듬 사이에 누적 차이를 만듦.
2. **기존 노트의 박자값에는 이미 시간 드리프트 보정이 반영되어 있음.** 따라서 BPM을 단순 변경하는 것은 오히려 노트의 실제 판정 시간을 크게 옮김. 200개 노트의 *기존 절대 판정 시각*을 기준으로 새 BPM=119.26 / 첫 박 기준 0.307초의 1/4박 단위(16분음표) 그리드에 재매핑.
3. **리듬 입력이 음악 강세에서 어긋나는 부분.** 196개 L/R 탭의 onset-strength 지표(노트 시점+29ms에서 측정)를 비교하면 종전 평균 0.913 → 재매핑 평균 1.084; 185/196개 시점의 값이 높아짐. 이 지표는 음향 사건의 근사치이며, 사용자의 실제 손맛이나 모든 악기 의도에 대한 청음 판정은 아님. 탭 시각 이동 평균 **18.3ms**, 최대 **48.3ms**.
4. **가독성.** 종전 900×450 가상 NoteLayer에서 1.4초 이내 동시 표시되는 L/R 노트의 본체 거리 126px 미만 쌍 **43개**. 개선본은 접근 원 배율 1.55까지 고려한 거리 168px 미만 쌍 **0개**, 40개 노트 위치만 변경. 최대 수정 거리 약 171px. 실제 게임 화면 크기에서 재검증 필요.
5. **소리 없는 Pop'n Dash 공격 이벤트.** 기존 19개 공격이 참조하는 `pop_*` ID 9종은 실제 탄막 구현에 빠져 있어 `Unknown pattern` 경고만 출력. 공유 탄막 패턴 라이브러리에서 9종을 정의하고 런타임 탄막 디렉터에 실제 스폰/곡선·방향전환/수명 처리를 연결. 에디터 역시 공유 라이브러리를 이용해 동일한 궤적을 미리 볼 수 있도록 함.
