# 곡 선택 — 한국어 제목 의미 번역 및 실제 범위 필터

## 한국어 곡명
기존의 단순한 영어·일본어 발음 표기를 없애고 **의미에 따른 한국어 제목**을 적용합니다. 이름은 창작 번역안이며 음악의 공식적인 한국어 제목을 주장하지 않습니다.

| 원본 제목 | 한국어 UI 제목 |
| --- | --- |
| BOOTBEAT | 시작의 박동 |
| Cotton Pulse | 솜결의 맥박 |
| Full-Band Hit | 합주의 일격 |
| Oddbeat Shuffle | 엇박자의 춤 |
| Pop'n Dash | 톡톡 튀는 질주 |
| 瞬奏 -SHUNSOU- | 찰나의 연주 |

- 원본 차트 `.asset`와 오디오 `AudioClip` / `songId`는 변경하지 않았습니다.
- 한국어/영어/일본어 화면에서 언어별 곡명을 표시합니다.
- 실제 씬의 초기 텍스트도 한국어로 수정했습니다. 다른 언어의 곡명/원본 제목을 검색해도 찾을 수 있습니다.
- 처음 보는 곡은 번역명이 없다면 원래 제목을 유지합니다.

## 필터 UI
기존 **8개의 미리 정의된 구간 버튼**은 모두 제거했습니다. 상단의 작은 **필터** 버튼을 누르면 2개의 드래그 범위 바가 있는 **하나의 작은 패널**이 열립니다.

- **레벨:** 1부터 15까지 오른쪽 손잡이를 마우스로 움직여 최댓값을 정합니다.
- **BPM:** 전체 차트의 최저·최고 BPM을 기준으로 범위를 자동 계산합니다. 새로운 곡이 늘어나도 범위를 적절히 확장합니다.
- 필터 결과는 드래그하면서 즉시 갱신됩니다. **완료**를 누르면 패널을 닫습니다.
- **초기화**는 레벨과 BPM 범위만 전체로 돌립니다. 검색어는 유지합니다.
- 우측 상단에는 필터를 통과한 곡 수가 소형으로 표시되고, 닫힌 상태에서는 필터가 적용됐을 때만 상태 표시가 나타납니다.
- 필터 패널을 연 상태에서 카트리지를 누르면 실수로 게임을 시작하지 않으며, 첫 클릭은 패널을 닫는 역할만 합니다.
- 정렬, 한국어 곡명 검색, 6곡 단위 페이지 이동, 자동 미리듣기 ON/OFF, 같은 카트리지 재클릭 시작은 유지합니다.

## 검증
- 새 `SongSelectRangeBar.cs` 및 Unity 메타파일 추가
- C# 중괄호 균형, 콜백 함수 존재, Scene YAML fileID 누락 0개 확인
- 6곡의 한국어 제목이 씬과 런타임 번역표 모두에 나타나는지 확인
- 원본 차트 .asset은 수정하지 않음
- **Unity Editor 컴파일, 화면 렌더링, 실제 마우스 드래그는 이 환경에서 직접 확인하지 못했습니다.**

## 2026-11-19 후속 수정
- 필터의 왼쪽 끝은 고정하고 오른쪽 손잡이만 움직이도록 변경함.
- 미리듣기 진행 막대 완전 삭제, ON/OFF 버튼만 유지.
- 카트리지 첫 클릭 시 선택한 카트리지가 위로 올라오고 두 번째 클릭에서는 기존 삽입 연출을 유지함.
- 탄막의 Mouse 씬 로더 연결을 수정하고 기존 채보의 긴 공격 공백을 보강함.
