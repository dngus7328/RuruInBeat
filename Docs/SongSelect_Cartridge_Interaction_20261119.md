# 카트리지 직접 선택 / 재클릭 게임 진입

이 문서는 Unity의 정식 곡 선택 씬 `Assets/Scene/SongSelectScene.unity` 에 적용된 동작을 설명합니다.

## 조작
- **첫 클릭**: 해당 카트리지를 선택합니다. 확대와 돌출 움직임, 오른쪽 정보 교체, 안내 문구 `한 번 더 누르면 게임 시작`이 나타납니다.
- **같은 카트리지 재클릭**: 해당 카트리지의 시각 복제가 오른쪽 게임 패키지로 빠르게 날아가면서 작아지고, **0.65초** 후 공유 `Mouse` 게임씬이 로드됩니다.
- **다른 카트리지 클릭 또는 휠로 변경**: 새로운 곡으로 이동하며 재클릭 대기 상태가 초기화됩니다.
- **전용 시작 버튼은 화면에서 비활성화**되어 있습니다. 카트리지 자체가 시작 버튼입니다.

## 클릭 입력
`SongSelectMenuUI.Update()`에서 마우스 왼쪽 누름을 직접 감지하고 각 활성 카트리지의 `RectTransform`을 검사합니다. 오래된 `Button.onClick` 행 리스너는 등록하지 않습니다. 같은 프레임에 이벤트가 두 번 실행되는 상황을 방지합니다. 첫/두 번째 클릭은 Unity Console에 각각 기록됩니다.

## 레벨 칸
모든 카트리지의 레벨 배지를 **가로 가운데, 하단 동일 위치**에 놓았습니다. 같은 크기이며 TMPro 가로/세로 중앙 정렬을 사용합니다.

## 확인
1. GitHub Desktop에서 `main`을 Pull합니다.
2. Unity에서 `Assets/Scene/SongSelectScene.unity`를 실행합니다.
3. 카트리지 클릭 시 Unity Console에 `[SongSelect] First cartridge click:` 메시지가 뜨는지 봅니다.
4. 같은 카트리지를 다시 누르면 `Second cartridge click` 메시지와 삽입 움직임이 나타나고 게임이 실행되어야 합니다.
5. 일시정지/곡 정보/미리듣기 등 다른 UI와 겹치지 않는지 확인합니다.

> GitHub 직렬화 참조 및 스크립트 연결 검사는 완료했지만, Unity Editor에서 직접 실행한 것은 아닙니다.
