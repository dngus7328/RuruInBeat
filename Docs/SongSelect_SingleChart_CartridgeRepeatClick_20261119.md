# 곡당 단일 채보 및 카트리지 재클릭 시작 (2026-11-19)

## 곡 선택 UI
- 화면에서 '게임 카트리지'와 '선택한 카트리지'라는 설명 제목을 사용하지 않습니다.
- 카트리지의 곡명, 레벨 뱃지는 유지합니다.
- 우측에 곡명·레벨·BPM·재생 시간과 미리듣기/게임 시작 버튼을 표시합니다.
- 난이도 명칭, 좌우 난이도 화살표는 Arcade 씬에서 비활성화했습니다. 단일 레벨은 '레벨 13'처럼 표시합니다.

## 데이터
- 동일 AudioClip에 여러 채보가 들어 있더라도 곡 선택 메뉴는 **1개만** 사용합니다.
- 기존 'MOUSE' 난이도 데이터가 있으면 그것을 우선 사용합니다. 그 외에는 기존 레벨 정렬에서 첫 항목을 사용합니다.
- 다른 채보 .asset 자체를 삭제하거나 수정하지 않습니다. 곡 선택 런타임에서만 하나로 선택합니다.

## 마우스 조작
- 카트리지를 **첫 클릭**하면 선택하고 소폭 전진/확대합니다.
- 같은 카트리지를 **다시 클릭**하면 짧은 삽입 애니메이션 후 공유 `Mouse` 씬에서 게임을 시작합니다.
- 처음 씬에 입장한 기본 선택 상태는 클릭 1회를 추가로 요구합니다. 휠로 곡을 선택해도 자동 시작하지 않습니다.
- 게임 시작 버튼을 직접 누르면 선택한 곡의 게임을 바로 시작할 수 있고 삽입 애니메이션도 동일하게 재생합니다.
- 삽입 애니메이션 도중 재입력과 미리듣기 재시작을 차단합니다.

## 기존 시스템
- 카탈로그 자동 새로고침/곡 목록/미리듣기/원본 곡명/게임씬 전달 기능은 유지합니다.
- 한·영·일 표시 문자열은 `SongSelectLocalization.cs`의 문구표에서 관리합니다.

## 검증
GitHub YAML 계층/컴포넌트 참조를 확인했습니다.
Unity Editor를 직접 실행하지 않았으므로 Game View/Play Mode에서 클릭과 전환 애니메이션, 오디오 정지, 폰트 표시를 최종 확인해야 합니다.
