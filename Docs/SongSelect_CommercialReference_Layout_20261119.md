# 곡 선택 화면 구조 개선 — 상용 PC 리듬게임 참조 (2026-11-19)

## 검토한 화면
- **DJMAX RESPECT V**: [Steam 공식 스크린샷](https://store.steampowered.com/app/960170/DJMAX_RESPECT_V/) / [Interface In Game 곡 선택 화면](https://interfaceingame.com/games/djmax-respect-v/). 선택 곡 자켓·정보와 탐색 목록을 구분하고, 선택 상태를 집중해서 보여주는 점을 참고.
- **EZ2ON REBOOT : R**: [공식 Steam 페이지](https://store.steampowered.com/app/1477590/EZ2ON_REBOOT__R/) / [TIME TRAVELER 페이지](https://store.steampowered.com/app/1758560/EZ2ON_REBOOT__R__TIME_TRAVELER/). 큰 자켓과 곡명을 먼저 보여주고 BPM 등 핵심 정보를 같은 정보 그룹으로 묶는 방식을 참고.

**복제하지 않은 부분**: 원작 타이포그래피, 실제 앨범 커버, 애니메이션, 특수 이펙트, 장식, 여러 키 수/난이도 선택. 《루루 인 비트》는 마우스 조작·곡당 채보 1개·카트리지 재클릭 시작이라는 별도 디자인을 유지한다.

## 이번 UI 수정
- 왼쪽/오른쪽 패널 비율을 약 **58:42**로 조정. 왼쪽은 카트리지 2열 3행 및 검색/정렬/레벨 필터/페이지 이동 유지.
- 오른쪽 게임 패키지 및 자켓 영역 비율을 균형 있게 조절. `songSelectJacket`를 실제로 표시하는 `JacketImage_Replaceable` 참조는 유지.
- 자켓 바로 아래 곡명, 그 다음에 **레벨 / BPM / 재생 시간** 3열의 정보 리본을 배치. 글자는 레이블 작게, 수치 크게 표시한다.
- 이전에 세로로 늘어섰던 레벨/BPM/곡 길이 텍스트를 기존 TMPro 오브젝트에 그대로 유지한 채 배치만 변경.
- 미리듣기는 오른쪽 하단 작은 ON/OFF 토글, 상태 시간, 진행바 구성 유지. OFF시 진행바를 어둡게 표시하고, 이미 토글에 명시된 OFF 상태 문구는 반복하지 않음.
- 처음 클릭 선택/같은 카트리지 재클릭 게임 진입 애니메이션과 곡 하나당 난이도 하나 원칙 유지.
- 새 문구는 기존 한국어·영어·일본어 표에서 처리.

## 실제 Unity 검증 항목
1. `Assets/Scene/SongSelectScene.unity` 열고 **Game View** 및 **Play Mode**에서 좌우 패널, 실제 자켓 비율과 레벨/BPM/재생 시간의 2행 정렬 확인.
2. 한국어, 영어, 일본어 순서로 문구가 줄바꿈/잘림 없이 표시되는지 확인 (한국어가 기본).
3. 재킷 Sprite가 없는 곡은 기존 자리표시자, 있는 곡은 실제 정사각형 이미지를 유지하는지 확인.
4. 미리듣기를 OFF하면 즉시 정지, ON하면 선택 곡의 15초 구간이 반복되는지 확인.
5. 곡 검색/정렬/필터/페이지 이동, 카트리지 첫 선택과 두 번째 클릭 게임 입장을 확인.
6. 화면비 16:9와 창 크기 변경 시 검색 및 작은 보조 버튼이 겹치지 않는지 확인.

**검증 범위:** GitHub scene YAML의 계층 참조, 컴포넌트 GUID 연결, 소스 구조를 검사. 이 환경에서는 Unity Editor를 실행할 수 없어 컴파일/실제 렌더링 테스트는 수행하지 못함.
