# 신규 3곡의 음악 해석 및 채보 재작업 기준 — 2026-11-18

> 이 문서는 오디오의 주파수대별 온셋/반복주기 분석과 기존 JSON 검수 결과이다. 실제 청음 및 Unity Play Mode 검증 결과가 아니다. 자동 분석으로 킥·스네어·특정 악기 정체를 확정할 수 없다.

## 기존 초안 검토 — 채보로 확정하지 않음

- `RhythmGameTheme_NORMAL.json` / `ArcadeGroove_NORMAL.json` / `MabatakiNoSenritsu_NORMAL.json`: 노트 위치가 x=0.13,0.305,0.48,0.655,0.83 등을 순회하고, y=0.19/0.81/0.5를 반복한다. 이것만으로 악기별 좌우 타격이나 손 이동이 설계되었다고 볼 수 없다.
- 공격 이벤트 역시 음악 구간에 맞춘 근거 없이 대략 일정 간격으로 배열된 부분이 있다.
- 이전 제시한 143.80 / 173.40 / 192.40은 고정 정확 BPM으로 볼 수 없다. 특히 `瞬きの旋律`의 192.40은 강한 세분 리듬과 메인 박을 혼동할 위험이 있다.
- 'BPM에 의한 초 변환 왕복 오차 0'은 자기 계산의 수학적 왕복성일 뿐, **음원과 판정이 일치한다는 증거가 아니다.**

## 악기/구간별 채보 설계 검토 포인트

### リズムゲームのテーマ
- 0~8초의 낮은 타격 밀도에서 점차 8~40초에 일정한 리듬으로 올라가는 구성을 유지. 처음부터 손을 크게 왕복시키지 않기.
- 40~56초의 저역과 중·고역 비중 변화, 56~80초의 저역 타격 강조, 80~112초의 중·고역 밀도 상승을 별도 프레이즈로 구분.
- 112~120초는 전체 음향 밀도 감소가 감지되므로 노트·탄막 동시 과밀을 피하고, 120초 이후 마무리 구간 처리.
- 목표 Lv.5 수준에서 **타격의 규칙성**을 배울 수 있도록 하되, 특정 악기 패턴은 귀로 확인 후 지정.

### Arcade Groove
- 0~56초까지 반복되는 리듬 요소를 바탕으로 **반복 패턴의 변형**을 설계.
- 56~64초 중·고역 온셋 급증: 우연한 난타가 아닌 짧은 타격 필인 후보. 클릭/휠 동선은 직전 프레이즈 끝에서 연결.
- 72~88초 저역 강조: 저역 악기 타격에 맞춘 위치 이동/강세 변화 후보.
- 88~96초 저역과 중·고역 비중 변화: 직전 프레이즈의 변형과 구분.
- 96~128초 재전개: 같은 리듬 모티프의 난도 확장. 탄막은 노트 핵심 리듬의 빈 공간을 중심으로 설계.
- 목표 Lv.9, 악기 교차와 엇박을 표현하되 불필요한 멀리뛰기 금지.

### 瞬きの旋律
- 0~8초 도입이 뒤 구간보다 약함: 과도한 첫 노트/탄막 지양.
- 32~48초 중·고역 온셋 증가: 멜로디/장식음 분석 후 타격 패턴을 세분할 후보 구간.
- 64~80초 저역 강화, 104~112초 음향 밀도 상승, 112~120초 상대적인 완화, 120~136초 재전개.
- BPM 192.40을 일괄 적용하지 말고 메인 박자 126~130대 변화를 먼저 확인. 연속 16분 타격/3:2 세분 리듬이 있는지 청음 확인.
- 목표 Lv.14라도 노트를 무작위로 늘리지 말고, **고밀도 리듬 구절 / 이동 구절 / 휠 구절 / 회피 구절**을 번갈아 설계.

## 노트·탄막 동시 설계 검수 조건

1. 노트 L/R의 결정은 실제 저역·중역·고역 악기 온셋 또는 모티프 반복에 근거를 남긴다.
2. 휠은 **지속음·연결음**이 들리는 구간에서만 사용하고 음원과 경로 종료가 일치하도록 한다.
3. 연속 노트의 공간 위치를 임의 순환하지 않는다. 이전 노트 이후 커서 이동 가능한 시간과 이동 방향을 계산한다.
4. 탄막은 별도 랜덤 이벤트가 아니라 프레이즈 변곡/강세와 연결되며, 경고·발사·통과 시각을 그 구간의 실제 BPM으로 환산한다.
5. 공격 예고/파편/일반탄이 노트, 휠, 마우스 커서의 경로를 동시에 봉쇄하지 않는지 **실제 게임 화면** 기준으로 테스트한다.
6. 자동 검사는 **초안용 안전망**이며 재미·음악성·인간 조작감을 증명하지 않는다.
