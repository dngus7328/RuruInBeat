# Full-Band Hit — 실제 WAV 기준 노트 타이밍 점검 기록
작업일: 2026-11-21 / 대상: `main` 브랜치 / 플레이 음원: `Assets/Song/Full-Band Hit.wav`

## 무엇을 직접 확인했나
- 실제 WAV를 ffmpeg로 디코딩해 전체 **129.56초**에 대해 분석했다.
- `Tools/ChartRework/fullband_music_structure_audit.py`에서 소리 변화를 **45–220Hz / 220–950Hz / 950–2600Hz / 2600–5400Hz**로 따로 분석했다. 이 값들은 악기 분리 스템이 아니라 **주파수 대역별 음향 변화의 대용치**다.
- 현재 Unity용 `FullBandHit_MOUSE.asset`와 편집용 `FullBandHit_MOUSE.json`의 노트, `MouseModeChartTiming.BeatToSeconds` 시간표를 대조했다.
- 각 노트에 대해 초 단위 판정 시각, 대역별 가까운 음향 타격, 시간 차, 근처 음량을 기록한다. **16박 단위**로 곡 전체 26개 구간의 타격 밀도와 채보 밀도도 기록한다.
- 분석 파일은 GitHub Actions `Mouse chart data checks` → `mouse-six-song-audio-timing-audit` 아티팩트의 `Reports/FullBandHit_note_musical_evidence.csv`, `Reports/FullBandHit_phrase_musical_evidence.json`으로 제공한다.
- 수정 전후 음악+타격음은 같은 아티팩트의 `fullband-before-clicks.mp3`, `fullband-after-clicks.mp3`으로 비교할 수 있다.

## 자동 검사의 정량 결과
| 항목 | 추가 수정 전 | 현재 |
|---|---:|---:|
| 채보 노트 수 | 394 | **389** |
| 원본 WAV의 검출된 4대역 음향 공격 중 하나에서 35ms 이내 | 381 / 394 | **389 / 389** |
| 35ms 범위 밖에 있는 노트 | 13 | **0** |

이 값은 **단지 오디오 트랜지언트 검출 근접도**다. 주의:
- 한 노트가 어떤 악기·음악 프레이즈를 표현해야 하는지는 별개다. 가까운 음향 공격이 있다고 해서 채보가 음악적으로 옳다는 뜻은 아니다.
- 35ms는 최종 판정 오차 허용치가 아니라 **검사 기준**이다. 신호 분석의 FFT 프레임 및 원본 음원 트랜지언트 정의 자체에 시간 불확실성이 남는다.
- 모든 들리는 소리를 노트로 만들 필요도 없다. 이 검사의 '강한 무채보 타격 후보'는 검수용 신호지표이지 새 노트 추가 지시가 아니다.
- **실제 Unity Play Mode에서의 오디오 출력 지연, 입력 이벤트 시간, 프레임/포커스/일시정지, 실제 재미와 리듬 의도는 별도 확인해야 한다.**
- 이전 PR #49의 **51개 자동 분석 기반 템포마커**도 이 검사를 통과했다는 이유로 '음악적으로 확정'이라고 할 수 없다.

## 왜 아직 완료가 아닌가
이 곡의 원래 채보는 대부분 노트 사이가 약 1박으로 구성되어 있었다. 단순한 시간차 검사는 리듬 패턴의 음악성과 난이도를 보장하지 않는다. 따라서 음악의 구간별 악기 패턴을 실제로 청음 확인하고, **각 노트가 어떤 소리를 따라가는지 389개 모두 명시한 채보 설계**를 해야 완성이라고 할 수 있다. 마지막 부분의 지속음 위에 놓였던 390,391,394번 삭제도 청음 확인이 필요한 보수적 수정이다.

1. **Full-Band Hit는 곡 선택 화면에서 선택해 실행**해야 한다. `Mouse.unity`를 에디터에서 바로 재생하면 Inspector가 `NewMouseChart 2.asset`(GUID `c7236f68a65f2ce4a9f022221f5f66ee`)를 참조한다. 곡 선택 시 `MouseModeSongSelection.CurrentChart`가 현재 곡을 덮어쓰는 구조이므로, 직접 실행하면 이 수정본을 테스트하는 게 아니다.

3. 16박 구간별 악기 패턴을 적고 노트 ID와 대응시키기. 왼쪽·오른쪽 클릭, 휠 시작·유지·종료를 모두 확인.
4. Unity Play Mode에서 노트 스폰, 판정 순간, 음악 출력, 음장치 지연을 검증하고 실제 타격감과 회피 동시 플레이 확인.
