# 《루루 인 비트》 전체 마우스 채보 탄막 다양화 — 2026-11-21

## 목표와 기준

플레이어 제보: 탄막이 좁은 공간에 지나치게 촘촘히 떨어지고, 채보와 탄막의 체감 비중이 비슷하며, 반복되는 탄막 패턴이 심심함.

**리듬 채보가 본체, 탄막은 조작·회피의 변화를 주는 보조 요소**로 설계한다. 탄환의 총량을 난이도로 착각하지 않는다. 음악 박자·노트 위치·종류·판정 시각·휠 경로·음원은 변경하지 않았다.

## 새 탄막 7종

- `mix_arc`: 좌우 번갈아 나오는 열린 부채꼴
- `mix_cross`: 서로 다른 박자에 반대쪽에서 들어오는 대각선 교차
- `mix_gate`: 2칸 이상의 빈 통로가 이동하는 3개 짧은 벽
- `mix_sweep`: 좌→우 다음 우→좌로 답하는 짧은 쓸기
- `mix_echo`: 왼쪽 호출, 오른쪽 응답을 번갈아 배치
- `mix_comet`: 이동하던 느린 씨앗탄이 두 갈래 방향으로 분열
- `mix_ribbon`: 위치와 진행 방향이 조금씩 바뀌는 곡선 흐름

각 이벤트 기본 탄환은 **9~15발**. 유저가 보는 캐릭터·노트와 겹치는 총량을 낮추면서, 회피 방법이 다른 패턴을 사용한다. `MouseModeBulletPatternLibrary`를 에디터/게임 공용 생성 소스로 사용한다.

## 추가 밀도 개선

`Pop'n Dash`의 기존 시그니처 9종은 이름을 유지한 채 발사 주기와 발사 수를 조정했다. 대표적으로 `pop_pinwheel` 48→24발, `pop_echo` 36→18발, `pop_twinfan` 32→12발. 본체가 잘 보이도록 이전에 자동 추가되던 중복탄도 제거했다.

낙하형 `rain`은 플레이용 차트에서 4~5줄로 줄였고, 채보에 명시된 `gap=7` 열린 통로를 런타임이 `gap=5`로 몰래 좁히던 버그를 수정했다. 새로운 기본 패턴의 폭·밀도는 차트 문자열에서 `spread`/`density`/`rotation`으로 설정하며, 파싱 과정에서 이 값이 사라지지 않도록 보완했다.

## 자동 검사 및 주의

- `Assets/Tests/Editor/MouseBulletMotifVarietyTests.cs`: 7종의 탄환 수·발사 가로 범위·하단 위험선에 남는 수평 빈 공간 확인, Pop'n Dash 9종 탄환 수 확인, 차트별 패턴 종류 확인, 인코딩된 밀도/분산 옵션 파싱 확인
- `.github/scripts/chart_static_audit.py`: 곡별 노트/편집 JSON 동기화, 패턴 등록, 짧은 초보 채보 공격 간격, rain 줄수 제한
- **주의:** 자동 계산은 사람의 회피 조작 가능성과 재미, 실제 Unity Play Mode에서 음악 싱크를 증명하지 못한다. 탄환 발사에 음악적 억양이 맞는지, 피노 이동과 함께 실제 회피 가능한지, 모든 곡을 마지막까지 끝낼 수 있는지는 별도 플레이 테스트가 필요하다.
- 상태: 실제 CI 결과는 GitHub Actions에서 최신 커밋 기준으로 확인한다. 검사 전/중 상태를 성공으로 표시하지 않는다.

원래 노트는 지우거나 바꾸지 않았으며, 문제가 있으면 각 변경 커밋의 이전 버전으로 복구할 수 있다.
