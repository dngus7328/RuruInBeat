# 루루 인 비트: 여섯 곡 채보 재배치 + 곡 선택 임시 시안 (2026-11-19)

## 목적
이 변경은 원곡을 재작곡하거나 채보를 자동 완성 판정하는 작업이 아니다.
PC 마우스 전용 리듬게임에서 음악을 따라 움직이는 시선/손 패턴, 판정음,
그리고 곡 선택 흐름을 개선하기 위한 **플레이 테스트 후보**다.

## 정식 채보 6개
|곡|기존 노트|수정 뒤|핵심 변경|
|---|---:|---:|---|
|BOOTBEAT Lv6|164|164|손 배치의 짧은 동기·응답 패턴, 주제별 시각 경로|
|Pop'n Dash Lv8|200|200|튀는 박자의 좌우 응답·회귀와 읽기 쉬운 표시 위치|
|Full-Band Hit Lv13|396|394|악기 타격 교대/구절별 응답, 일부 고밀도 시각 이동 제한|
|Cotton Pulse Lv5|227|227|이미 오디오 분석으로 조정한 손 종류 유지, 화면 위치/동선 보완|
|Oddbeat Shuffle Lv9|330|329|기존 오디오 분석 손 종류 유지, 반복적 시선 이동 완화|
|瞬奏 -SHUNSOU- Lv14|398|397|기존 손 종류 유지, 고속 구간의 노트 시각 동선 완화|

- 마우스 휠 롱노트의 시작·종료·경로는 그대로 보존한다.
- 기존 남은 노트의 박자, BPM, 오디오 싱크, 탄막 공격 큐 모두 보존한다.
- 정적 비교로 Editor JSON과 Unity ScriptableObject .asset의 노트 kind/beat/position 수가 같음을 확인했다.
- 첫 3곡은 전체 원음원 접근이 어려워 **원곡 청음/시각 오디오 분석을 완료했다고 주장하지 않는다.**
- 신곡 3곡은 앞선 오디오 분석을 통해 나뉜 좌/우 클릭 배정을 유지하고 화면 위치만 보완했다.
- 입력 판정은 노트의 정해진 시간에만 적용되며, 노트 좌표를 직접 클릭해야 하는 방식으로 바꾸지 않는다.

## 타격음
- 기존 프로젝트에 들어 있던 PERFECT/GREAT/GOOD/MISS, 휠 시작/해제, 홀드, 피노 피격 WAV 14개를 `MouseNoteAudioPalette`으로 연결했다.
- 공통 `Mouse.unity` 재생 시 `NoteSoundManager`가 없으면 오디오용 GameObject만 자동 생성한다.
- 노트 판정 코드가 첫 타격에서 소리 관리자를 다시 찾아 연결하도록 수정했다.
- 기존 Inspector에 직접 연결한 판정음은 우선한다.
- 음악 박자/노트 판정/사용자 조작/UI 배치는 바꾸지 않는다.

## 곡 선택: **임시 도형 UI, 최종 일러스트 아님**
- 상용 PC 리듬게임의 곡 목록·선택 정보·미리듣기·정렬·조작 흐름을 도형으로 제공한다.
- 루루의 게임 취향을 반영한 `BEAT CARTRIDGES`, `CARTRIDGE LOADED`, `LOAD & PLAY`은 **임시 표시 문구**다. 텍스트를 Unity에서 이미 수정했다면 덮어쓰지 않는다.
- 기존 여섯 개의 보이는 버튼 슬롯을 재사용하며, 실제 곡 목록은 채보 .asset 자동 목록을 사용한다. 곡 수를 6으로 하드코딩하지 않는다.
- F2=제목/레벨/BPM 정렬 전환. 방향키·PgUp/PgDn·Enter·ESC 등 PC UI 보조 조작. 마우스 목록 선택/휠/클릭은 그대로 사용.
- 선택된 행에는 절제된 무광 외곽선 피드백을 준다.
- 재킷이 비어 있는 동안만 기본 AudioSource 스펙트럼 도형을 보여준다(영구 그래픽 아님).
- `MouseModeChartAsset.songSelectJacket` 필드에 나중에 곡별 Sprite를 연결해 교체한다. `backgroundImage`는 인게임 전용으로 따로 보존.
- **기존 SongSelectScene.unity 및 모든 RectTransform/anchor/size/position은 수정하지 않았다.**
- 나중에 사용자가 UI를 직접 옮겨도 이 변경의 런타임 코드는 원래 배치를 되돌리지 않는다.

## 확인할 사항
1. Unity가 스크립트를 컴파일하고 게임용 Mouse 씬이 실행되는지 확인.
2. 음원별 채보 정확도, 반복/변주, 휠 중 입력, 피노 탄막 회피의 자연스러움 직접 플레이하며 검수.
3. 실제 곡 선택 UI에서 리스트 정렬, 미리듣기 볼륨·시간, 기본 이미지와 곡별 커버 교체 테스트.
4. 과도한 클릭음과 음악의 밸런스를 확인하고 Inspector에서 noteVolume 조정.
5. 특정 구간이 음악에서 어긋나면 이 브랜치의 채보는 확정하지 않고, 구간별로 원음원과 비교해 재작업.

**실제 Unity Play Mode/청음 통합 검증은 이 환경에서 실행하지 못했다.**
