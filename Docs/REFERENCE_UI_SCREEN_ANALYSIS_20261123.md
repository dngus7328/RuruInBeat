# 《루루 인 비트》 실제 게임 화면 기반 UI 레퍼런스 분석
기록: 2026-11-23. **게임 화면 스크린샷/상세 페이지를 실제로 조회한 12개 사례**만 기록. 게임을 직접 실행해 프레임 단위로 측정하거나 모든 메뉴를 플레이한 것이 아니다. **화면에서 확인한 사실**과 **루루 인 비트에 적용할 설계 결정**을 구분한다.

> 이 문서는 “이 게임을 참고했다”는 이름 나열이 아니라 스크린샷 링크로 검증 가능한 비교다. 원작의 그림/아이콘/화면을 복사해서 사용하는 디자인 지시가 아니다. 이 결과는 다음 이미지 제작 및 화면 시안의 근거이며, 그림 제작이 끝났다는 뜻이 아니다.

## C. 캐릭터 화풍을 UI에 적용하는 **구체적 번역 규칙**

1. **‘보라색 버튼’은 화풍이 아니다.** 루루/피노의 선 질감은 짙고 깨끗한 외곽선, 내부 선 최소화, 단단한 셀 명암. UI 버튼도 **두께가 아닌 면의 실루엣과 대조**로 개성을 보인다.
2. **‘한쪽 사선 컷’만 반복해서 독특해지는 것도 아니다.** 캐릭터의 커다란 머리·날개처럼 *형태 전체가 읽히는 구도*가 먼저. 사선은 큰 선택 영역에만 최소한 활용하고, 작은 버튼에는 정돈된 형태도 허용.
3. **배경/재킷은 별도 일러스트를 새로 그린다.** 루루/피노 전신 원본을 얹어놓은 화면은 임시 시안일 뿐. 새 타이틀 일러스트·곡별 스토리가 느껴지는 재킷·배경으로 완성한다.
4. **선택 시 드러나는 것은 이미지의 크기/밝기와 중심 소재다.** 레이어 위에 별·화살표를 수십 개 추가하는 방식 아님.
5. **동일한 공용 패널을 화면마다 같은 크기로 반복하지 않는다.** 기능 패널은 공용이어도 배경 구도·캐릭터 동작·타이포그래피와 곡 재킷의 배치가 화면 개성을 결정한다.
6. **모방은 UX 구조까지만.** 다른 게임의 재킷·아이콘·구체 메뉴 아트는 복제하지 않는다.

## D. 다음 디자인 산출물에 요구할 정확한 근거

- 전체 화면 시안에는 **“어느 게임의 어느 스크린샷에서 어떤 원리를 가져왔는지”** 주석으로 표시한다. 게임 이름만 쓰는 것은 참고 증거 아님.
- 기존 Unity 화면 캡처와 새 시안을 **나란히 비교**하여 변경하는 위치/아트 분리/Unity 입력이 막히지 않는지 판단한다.
- 타이틀 루루는 사용자 제공 원본을 기준으로 새 일러스트를 그린다. 원본 몸체/의상/얼굴의 구조를 새로 해석해서 바꾸지 않는다.
- 결과/튜토리얼의 피노와 루루도 원본에 맞춘 **새 포즈와 표정 일러스트**가 필요하다. 단순 배경 제거 원본만이 완성품은 아니다.
- 6곡 재킷은 **실제 곡을 듣고** 모티프를 잡는다. 지금까지 제목만 보고 제안한 ‘도형 카드 4개’ 같은 콘셉트는 최종 디자인으로 승인된 것이 아님.
- 참고 분석 문서만 만들고 새 그림/Unity 장면이 없는 상태를 **아트 제작 완료라고 하지 않는다**.
