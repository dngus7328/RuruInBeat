## 노트 배치
- 좌/우클릭은 **노트를 직접 클릭하는 방식이 아니다**. 기존 위치 무관 판정을 유지.
- **참고 기준:** osu!의 템포·오프셋 확인/박자 스냅, Rhythm Doctor의 반복적으로 학습 가능한 타격 구조, Just Shapes & Beats의 곡 프레이즈를 따라가는 수동 탄막 설계. 감지된 음원 피크를 노트 119개에 각각 자동 배치하는 이전 방식은 폐기했다.
- 도입 5개 노트는 검출된 멜로디 타격 시점을 유지하고, 반복 박동이 뚜렷해지는 20박부터는 **4/4 마디의 반복 리듬**으로 전환한다. 후반의 16박 프레이즈는 7개 노트를 기본으로 하고, 일부 악센트를 8분/16분 단위로 달리하여 리듬 변화를 준다.
- 음악 구절별로 **좌우 교대, 완만한 호, 짧은 대각선 진행**을 사용한다. 미리 정해 둔 14개의 위치를 재사용하지 않고, 프레이즈마다 미세한 변형으로 위치를 조정한다. 무작위 흩뿌리기는 하지 않는다.
- 동일한 화면 좌표를 두 번 사용하지 않는다. 약 1.75초 안에 노트 본체가 충돌하지 않도록 확인한다.
- 시작 16박에는 7개 노트로 진입하고, 이후 16박 프레이즈마다 10~12개 노트의 반복·변형 타격 구조를 사용한다. 같은 박을 기준으로 시작·끝을 예측할 수 있도록 강박을 유지한다. 초반부터 동시 입력을 요구하지 않는다.
- 휠 입력은 4번만 등장하고, **휠 시작 전·해제 후 약 1.2박의 회복 시간**을 둔다. 휠 입력을 하면서 좌우 버튼을 함께 누를 필요가 없다.
- 접근 원은 판정 순간을 알려주는 타이밍 가이드이며, 원의 이동/축소 및 좌우 입력 규칙은 변경하지 않는다.

## 탄막
- **35회 공격 이벤트:** 4/8박 간격으로 마디 경계에 발사한다. 첫 공격은 약 9초 지점, 이후 **8박(2마디) 단위**로 전개하고 곡 중간 전환 지점에는 4박 뒤 추가 공격을 배치한다. 4/4 리듬 구조를 지키면서도 회피 파동을 끊지 않는 초안이다. 전체 예정 투사체 약 1,567발(패턴 생성 기준).
- 4개 패턴의 특성은 유지하되 **5차례 부채꼴과 중앙 반격, 좌우 응답과 중앙 펄스, 5행 이동 통로와 중앙 닫힘 탄환, 8차례 엇박 사격과 중앙 역박**으로 확장했다. 각 패턴에는 회피가 가능한 통로를 남긴다.
- 이전에 수정한 `BulletLayer` 크기를 유지하고, 노트와 탄막의 입력 판정 기준은 건드리지 않았다.
- 접근 원/노트 크기: Unity Inspector에서 직접 설정한 배율 그대로 표시한다. 이전 코드의 **2.2배 접근 원 강제 상한**과 **124px 노트 크기 강제 상한**은 제거했다. 설정한 크기가 실제 화면에 맞지 않으면 경고만 표시하며 자동 축소하지 않는다.
- 피노의 하단 이동 제한 범위는 그대로. 탄막을 피하는 중에도 위치 상관없이 리듬 판정을 낼 수 있다.

## 파일과 재현
- 실제 게임용: `Assets/MouseMode/ChartSystem/Charts/BOOTBEAT_MOUSE_LV6.asset`
- 채보 편집용 원본: `Assets/Editor/BOOTBEAT_MOUSE_LV6.json`
- 기존 파일명에 `LV6`이 남는 것은 **Unity GUID 및 카탈로그 참조를 유지하기 위한 호환 목적**이다. 실제 게임 화면에서는 파일 내부의 `level: 1`을 사용한다.
- `Assets/Scripts/MousePlay/MouseModeBulletPatternLibrary.cs`: 곡별 4개 공격 패턴.
- `Assets/Tests/Editor/BootbeatRechartedGameplayTests.cs`: 레벨, 노트 개수, 16박 프레이즈 반복, 동시 입력 부재, 좌표 비중복, 휠 회복 구간, **4/8박 마디 기반 탄막 및 30~32발 패턴**, Inspector 원/노트 크기 유지 검사.

## 난이도·이름 분리 규칙
- 곡 제목이나 콘셉트만으로 레벨을 지정하지 않는다. **「시작의 박동」이라는 제목도 난이도 1을 강제하지 않는다.**
- 현재 레벨 4 표기는 약 198개 노트, 휠 조작 4회, 35회 패턴 공격과 회피 부담에 따른 **임시 수치**다. 실제 플레이 후 조정한다.
- 노트는 음악적 타격 패턴의 반복·변주를 우선하고, 무의미한 공백을 줄인다. 소리가 나는 모든 시점에 노트를 붙이거나, 자동 검출 결과를 박자 정확도로 오인하지 않는다.
- 탄막은 피노의 초기 위치를 포함한 중앙을 통과하는 펄스를 추가하고, 정지 상태로 모든 공격을 피하는 영구 안전 위치를 줄인다. 양쪽 회피 경로는 남겨둔다.

## 실제 플레이 검수 사항
- 초반 타격 타이밍의 자연스러움, 휠과 일반 클릭의 전환, 적의 발사 전 존재감.
- 탄막의 실제 회피 난이도, 노트의 시야 간섭, 마지막 구간의 긴장감.
- Unity EditMode와 정적 데이터 검사는 이 항목의 실제 체감을 보장하지 않으므로, 플레이 후 조절해야 한다.

이 PR은 **《시작의 박동》 하나에만 적용**된다. 다른 곡의 채보·음원은 수정하지 않는다.

## 검증 상태
- 데이터 검사는 통과하더라도 이것만으로 난이도와 실제 회피 감각을 보장할 수 없다.
- Inspector에서 크게 설정한 접근 원은 의도대로 크게 보이며, 가독성 문제가 있다면 자동으로 작아지지 않는다.
- 탄막의 실제 피격 빈도와 저사양 PC 렌더 성능은 Unity Play Mode에서 확인이 필요하다.

## 조사한 상용 게임·제작 자료
- [osu! — How to time songs](https://osu.ppy.sh/wiki/en/Guides/How_to_time_songs): 템포·오프셋을 먼저 잡고 시작/중간/끝을 메트로놈과 플레이로 검증
- [osu! — Beat snapping](https://osu.ppy.sh/wiki/en/Beatmapping/Beat_snapping): 박자 분할 단위에 맞춰 히트 오브젝트 배치
- [Rhythm Doctor — Audio Offset and Song BPM](https://rd-editor-docs.github.io/adding-a-song/audio-offset-and-song-bpm/): 정확한 곡 시작점과 일관된 박동 확인
- [Just Shapes & Beats 제작자 인터뷰](https://www.gamedeveloper.com/design/how-jams-become-levels-in-the-co-op-bullet-hell-musical-i-just-shapes-beats-i-): 곡 테마·프레이즈를 따라가는 수동 공격 패턴과 사전 예고

**검증상 주의:** 자료는 제작 원칙의 근거일 뿐 BOOTBEAT의 BPM이나 악기 구성을 증명하지 않는다. 현재 템포맵은 이전 음원 분석 초안(37개 변화 지점)을 유지하며, 실제 원곡과의 동기화 및 악기별 채보의 음악성은 별도 재생·플레이 검증이 필요하다. 자동 검사 성공만으로 완성 선언하지 않는다.
