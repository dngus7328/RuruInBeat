# 곡 선택 — 한국어 제목과 필터 확장

## 화면 제목 (원본 에셋 유지)

| 채보의 원래 표시 제목 | 한국어 표시 제목 |
| --- | --- |
| BOOTBEAT | 부트비트 |
| Cotton Pulse | 코튼 펄스 |
| Full-Band Hit | 풀밴드 히트 |
| Oddbeat Shuffle | 엇박 셔플 |
| Pop'n Dash | 팝 앤 대시 |
| 瞬奏 -SHUNSOU- | 슌소우 |

**원본 `MouseModeChartAsset.displayTitle`, `songId`, 오디오 클립, 파일명은 변경하지 않았습니다.** 씬 초기 TMPro와 런타임 곡 선택 라벨만 번역합니다. 한국어·영어·일본어 표는 `SongSelectLocalization.cs`의 `SongTitles`에 있고, 현재 등록되지 않은 곡은 원래 제목을 그대로 표시합니다.

검색은 한국어 제목뿐 아니라 원래 영어·일본어 제목과 일치하는 곡도 찾습니다. 곡명 정렬 또한 현재 표시 언어를 기준으로 합니다.

## 필터
상단 검색창 옆 **필터** 버튼을 누르면 작은 팝업이 열립니다.

- **레벨:** 전체 / 1–5 / 6–10 / 11–15
- **BPM:** 전체 / 129 이하 / 130–169 / 170 이상
- 두 조건은 서로 동시에 적용됩니다. 숫자는 플레이 화면에 표시하는 반올림 BPM 기준입니다.
- **초기화**는 레벨·BPM 필터만 전체로 돌립니다. 검색어는 그대로 남습니다.
- 팝업이 열려 있는 동안 안쪽 카트리지를 클릭하는 사고를 방지했습니다.
- 일치하는 곡이 없으면 기존 ‘검색 결과가 없어요’ 문구를 표시합니다.
- 한 화면에 6곡, 7곡 이상일 때만 페이지 이동 버튼 표시, 마우스 휠도 유지합니다.

## 유지
- 카트리지 첫 클릭으로 곡 선택, 같은 카트리지 재클릭으로 삽입 애니메이션 후 게임 시작
- 곡당 채보·난이도 하나
- 자동 미리듣기 ON/OFF와 저장 기능
- 실제 자켓 이미지는 원래 차트의 `songSelectJacket` 경로 사용

## 검증 범위
GitHub의 실제 Unity 직렬화 씬에서 제목 문자열 6종을 확인했고, 컴포넌트 fileID 참조 누락 0건, C# 중괄호 구조와 UI 콜백 메서드 존재를 정적으로 확인했습니다. **Unity Editor에서 직접 빌드하거나 Play Mode 조작을 검증하지는 못했습니다.**
