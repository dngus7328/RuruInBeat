# 루루 인 비트 — 이미지 제작 이전 요약
> 최신 기준은 [통합 제작 명세서 §22](MASTER_PRODUCTION_SPEC_20261128.md)이다. 이 문서는 이전 요약이며 현재 이미지·UI·일러스트·리소스 제작 및 Unity 적용은 보류한다. 독립적으로 제작 작업을 시작하는 근거로 사용할 수 없다.

## 시각 방향
게임기 콘셉트의 일본 서브컬처풍 PC 인디 리듬게임. 실제 게임기 본체가 아니라 선택·입력 반응과 상태 표시, 화면 전환에 콘셉트를 반영한다.
경계가 명확한 불투명 단색 면, 넓은 여백, 절제된 그래픽. 색상과 형태로 정보 및 선택 상태를 구분한다. 화면 전체 구도를 먼저 설계하고 사선·별·음반·테두리·아이콘을 반복하지 않는다. 네온·글로우·금속·그라데이션 남용 금지.
사용자가 선호한 라벤더 아케이드 7화면 시안의 분위기를 유지한다. 확정 루루·피노 원본의 외형·그림체·의상·비율·색·선질은 변경하지 않는다. 장면별 구도·포즈·표정은 재구성할 수 있다. 휴대용 게임기 본체 프레임, 동물형 대체 캐릭터, 네온 레인형 시안은 폐기한다.

## PC UI
1920×1080 기준. 일반 버튼 높이 40~48px, 주요 48~64px, 일반 글자 20~24px, 보조 16~18px 권장(확정 규격 아님). 필요한 곳만 1~2px 선. 텍스트 메뉴와 선택 색면을 활용하며 터치용 대형 버튼 및 카드 반복을 피한다.
타이틀: 로고와 일러스트, 작은 CLICK TO START만. 메인 메뉴 별도, 크레딧은 하단 보조 메뉴.
곡 선택: 패키지처럼 편집한 재킷/상세 정보, 검색·정렬·분류·자동 미리듣기·플레이. 단일 채보. 미리듣기 전용 버튼은 신규 제작하지 않는다.
인게임: 상단 HUD만 디자인. 재킷/곡명/안정화/콤보/점수. 안정화 외곽 640×28, 내부 628×20, 사선 9개로 10구간, 흰색 채움은 Unity에서 상태별 색 변경. 기존 게임판·노트·탄막 임의 변경 금지.
설정: 라벨과 조작 부품 정렬. 스토리·튜토리얼: 대화와 실제 조작 안내 중심. 결과: 점수·랭크·피노 반응 중심. 로딩·일시정지: 필수 정보와 기능만.

## 제작
대상 화면별 실제 참고 게임 화면을 확인한다. CHUNITHM(게이지), DJMAX RESPECT V(PC 목록·결과), Muse Dash(캐릭터와 UI), UNBEATABLE(편집 디자인). 외형 복제 금지.
한 화면씩 충분한 해상도로 디자인하고 검수한 뒤 기능별 부품으로 분리. 콜라주를 최종 리소스로 전달하지 않는다. 투명 PNG, 배경·캐릭터·로고·UI 독립, 동적 글자/숫자는 TMP Paperlogy 7Bold. 기존 자산은 품질과 필요에 따라 유지 또는 교체. 과거 개별 부품 작업은 우선순위로 강제하지 않는다.
요청하지 않은 기능, 난이도, 게임판, 캐릭터 설정 추가 금지. 실제 Unity 적용 및 실행 검증 전 완료 주장 금지.
